# My Workouts V4 - Release notes

## Version 4.0.0 source package
- Separate Android package ID: `com.myworkout.v4`.
- New first-launch 8-week progressive muscle gain programme from 2 Nov to 27 Dec 2026.
- Sunday active recovery includes easy cardio, full-body yoga/stretching and breathing.
- Excel template includes a Date column; original `Weekly Plan` and `Instructions` sheets are retained.
- Optional populated 8-week Excel workbook included.
- Bundled Excel template available from Workout Library and copied to app Documents when native file access is available.
- V4 workout and health storage namespaces separated from V3.
- GitHub Actions Android debug APK workflow included.

## Release qualification
This is a GitHub-ready source package. It is not represented as a compiled, installed, or device-tested APK. Android build and integration checks must be completed by running the included workflow and testing the resulting APK.
